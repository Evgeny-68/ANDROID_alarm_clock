# Соня — мульт-будильник

Проект Android на Kotlin и Jetpack Compose. Оригинальный персонаж в духе классической сказочной мультипликации: золотистый корпус, два верхних звонка, большие глаза, щёчки и улыбка. Изображения и сторонние графические ресурсы не нужны: всё рисуется Canvas.

## Запуск

1. В Android Studio выберите **Open** и откройте папку `ToonAlarm`.
2. Для Gradle выберите **Embedded JDK 17** или совместимый JDK. Установите Android SDK Platform 35 через SDK Manager.
3. Дождитесь Gradle Sync и нажмите **Run**. Минимальная версия Android — 8.0 (API 26).
4. Разрешите уведомления. Выберите время, нажмите «Завести будильник». На Android 12+ приложение при необходимости откроет системное разрешение точных будильников; после разрешения вернитесь и нажмите кнопку снова.

## Поведение

- Сон автоматически включается с 22:00 до 07:00 по местному времени телефона. Глаза закрываются, корпус плавно дышит, появляется сонный пузырёк.
- При сигнале глаза открываются, звонки трясутся, персонаж покачивается и подпрыгивает. Стрелки показывают текущее время.
- «День / Ночь» меняет режим для просмотра. «Показать пробуждение» запускает анимацию на 6,5 секунды без звука и без изменения назначенного будильника.
- Поддерживается один однократный будильник. Если выбранное время уже прошло, сигнал назначается на завтра. Новый будильник заменяет предыдущий.
- Сигнал работает через системный AlarmManager и foreground service, даже когда интерфейс закрыт. В уведомлении есть остановка. Нажмите уведомление для открытия анимированного экрана: автоматическое открытие поверх блокировки не реализовано.
- «Ещё 5 минут» назначает новый точный сигнал. Звук автоматически отключается через 10 минут. На Android 8 системный Ringtone может звучать без повторения; зацикливание включается с Android 9.
- После перезагрузки будущий сигнал восстанавливается; пропущенный переносится на следующий выбранный час. Изменение часового пояса или системного времени пересчитывает сигнал по выбранным часам и минутам.

## Где менять оформление

`app/src/main/java/com/example/toonalarm/MainActivity.kt`: `ClockCharacter` — рисунок, `AlarmScreen` — интерфейс. Амплитуда дыхания `.025f/.045f`, прыжка `26`, встряхивания `7`; ночные часы задаются в `AlarmScreen`.

`Alarms.kt`: планирование, восстановление, звук, вибрация и уведомление. `AndroidManifest.xml`: разрешения и компоненты.

## Проверка на устройстве

1. Установите сигнал на 1–2 минуты вперёд, сверните приложение и заблокируйте экран. Проверьте звук, вибрацию, уведомление и открытие персонажа по нажатию.
2. Остановите сигнал из приложения и отдельно из уведомления; убедитесь, что звук и вибрация прекращаются.
3. Проверьте «Ещё 5 минут», замену и отмену сигнала, перезагрузку телефона с будущим сигналом.
4. Проверьте режим сна, демонстрацию, поворот экрана и крупный шрифт.

Проект не собирался в текущей среде: здесь отсутствуют JDK, Gradle и Android SDK. Проверка APK и фонового срабатывания требуется в Android Studio и на устройстве. Для публикации нужны отдельная проверка требований магазина и расширенное тестирование.

Документация: https://developer.android.com/develop/background-work/services/alarms и https://developer.android.com/develop/ui/compose/animation/value-based.
